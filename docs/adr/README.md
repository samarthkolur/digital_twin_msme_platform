# Architecture Decision Records

This folder is for standalone ADRs — one file per decision, using the
`NNNN-short-title.md` naming convention (e.g. `0001-polyglot-monorepo.md`).

Every design decision made so far is already tracked in
[`design.md`](../../design.md) §15 ("Design Decisions") as a `DD-NNN` row
(ID, decision, rationale) — that table remains the authoritative log and
numbering sequence. Promote a `DD-NNN` to a full ADR file here when it needs
more than a one-line rationale (a real trade-off writeup, alternatives
considered, consequences). Keep the `design.md` row as the index entry and
link it to the ADR file rather than duplicating the content.
