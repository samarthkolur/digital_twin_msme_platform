# Architecture

This folder is for standalone architecture documentation (diagrams, sequence
flows, deep dives on a single subsystem) as the system outgrows a single
section of `design.md`.

Right now, [`design.md`](../../design.md) §6 ("System Architecture") is still
the canonical, up-to-date description of the system — layer architecture,
the Digital Cousin state model, and the hardware/edge/copilot/dashboard
module breakdowns. Start there. Add files here once a topic needs more space
(e.g. a detailed sequence diagram) than a PRD section can hold, and link back
to it from the relevant `design.md` section.
