# Hardware

This folder is for hardware documentation: wiring diagrams, sensor
datasheets/references, the retrofit mounting protocol, and bill-of-materials
notes for the pilot machine(s).

[`design.md`](../../design.md) §6.2 ("Hardware Module") currently holds the
hardware design as prose (ADXL345 accelerometer + DS18B20 temperature sensor
over SPI/1-Wire, Raspberry Pi target, the `SensorProvider` simulated/hardware
abstraction in DD-003). Add files here once hardware procurement and pilot
machine identification (§24 Pending Tasks) produce real wiring diagrams,
datasheets, or retrofit photos, and link them back from §6.2.
