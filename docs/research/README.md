# Research

This folder is for research notes, literature review, and evaluation
write-ups that are too long-form for the PRD itself (paper drafts, dataset
notes, experiment logs, related-work surveys).

[`design.md`](../../design.md) §8 ("Novelty and Research Contribution") and
§9 ("Evaluation Metrics") currently hold the project's research framing and
success criteria. Add files here as the ML/evaluation work in §24 (Pending
Tasks) produces real experiment results, and link them back from those
sections.
